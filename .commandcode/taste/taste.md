# Taste

## Workflow

- Dislikes long-running tasks and long verification/polish loops; imposes explicit time budgets ("don't take more than 10 minutes") and wants the visible result matched quickly, then a wrap-up report instead of continued fine-tuning. Confidence: 0.75

## Editing

- When matching a reference design, keep the existing working structure/treatment and change only the one thing requested (e.g. the edge shape); full rewrites that drop previously good details (rims, panels, glows) get rejected as "you ruined it more". Confidence: 0.7
- When a reference image is supplied, actually inspect/measure it before editing (zoom in on the region, trace the geometry) instead of guessing from a glance; implementing the wrong shape and being told "read the image" again is treated as a serious failure. Confidence: 0.7
